# Faber pt-BR medium

`model.onnx` and `model.onnx.json` are from [Trelis/piper-pt-br-faber-medium](https://huggingface.co/Trelis/piper-pt-br-faber-medium), licensed CC0. The model is served by this site; it is not fetched from Hugging Face at runtime.

The browser runtime is built from `@mintplex-labs/piper-tts-web` (MIT), `@diffusionstudio/piper-wasm` (MIT), and `onnxruntime-web` (MIT) with `npm run build:voice`. The generated explanations in `audio/explanations/` were synthesized with this model.
